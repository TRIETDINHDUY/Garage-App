REST API Endpoints (called by ClaimCenter)
Method Endpoint Description Direction

POST /api/garage/estimates Submit billing estimate CC → App
GET /api/garage/repair-orders/{id}/status Poll repair order status CC polls App
PUT /api/garage/repair-orders/{id}/status Update repair order status CC → App
GET /api/garage/repair-orders/claim/{claimNumber} Get all repair orders for a claim CC polls App
GET /api/garage/estimates/claim/{claimNumber} Get billing estimates for a claim CC polls App
